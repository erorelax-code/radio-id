# Radio ID v12

Najważniejsza zmiana: wszystkie zewnętrzne streamy są odtwarzane przez backend Radio ID, z obsługą przekierowań, Range i ponownego łączenia. Fixed streams PRL, Sami Swoi i Fix mają własne aliasy. Service Worker ma nowy cache v12.

Po wdrożeniu na Render odśwież stronę. Jeśli przeglądarka trzyma starą wersję, zamknij kartę Radio ID i otwórz adres ponownie.
